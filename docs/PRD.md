## 1. 产品目标

SkiPal（滑雪伴侣）是面向滑雪爱好者的 iOS + watchOS 应用：记录每一次滑行的 GPS 轨迹，
实时给出速度、海拔、距离与坡度，结束后产出统计、成就与可分享的雪场卡片。

**目标用户**

- 周末固定去雪场的中级及以上滑雪者（以国内崇礼/张家口/新疆为主，兼容海外雪场）
- 教练 / 雪友：需要把一次滑行拆解成可复盘的数据
- 佩戴 Apple Watch 的用户：希望手表端直接看到关键指标

**核心场景**

1. 上山前：查看雪场天气、5 日预报与雪质指数，决定去哪条道
2. 滑行中：一键开始记录，后台持续定位，实时看速度/坡度，自动识别雪场
3. 摔倒时：跌倒检测触发，提示是否联系紧急联系人
4. 下山后：回看轨迹、对比个人最佳、让 AI 教练点评、生成分享卡片

**成功指标**

- 一次完整滑行（记录 → 结束 → 生成卡片）不超过 3 次点击
- 记录过程中不出现因定位丢失导致的轨迹断裂
- 分享卡片在社交平台上一眼能看懂速度、最长距离与雪场

## 2. 产品原则

以下为全局业务规则，所有变更必须遵守：

- **离线可用**：雪场无网络时也能记录、统计、分享，核心能力不放在云端
- **不打扰**：后台定位只在记录中开启，结束即停；不索取无关权限；权限在功能首次使用时申请
- **手套可用**：关键按钮点击区域不小于 60 pt
- **隐私**：滑行数据默认只存本机；开启 iCloud 同步后写入用户自己的 CloudKit 私有库

## 3. 范围

**已有能力（MVP 与第二、三阶段，2026-03 前完成，见 [docs/history/](history/)）**：GPS 记录、地图、历史、
统计与成就、分享卡片、雪场识别、天气与雪质、AI 教练、跌倒检测、视频录制、Apple Watch 同步、CloudKit 同步、中英双语。
其中部分实现未接入界面，见 [architecture.md](architecture.md#并行--未接线的实现修改前先确认)。

**非目标**

- 不做账号体系与社交关系链
- 不把核心能力迁移到必须联网的云服务
