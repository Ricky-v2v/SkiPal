## 1. 产品目标

SkiPal（滑雪伴侣）是面向滑雪爱好者的 iOS + watchOS 应用：记录每一次滑行的 GPS 轨迹，
实时给出速度、海拔、距离与坡度，结束后产出统计、成就与可分享的雪场卡片。

**目标用户**

- 周末固定去雪场的中级及以上滑雪者（以国内崇礼/张家口/新疆为主，兼容海外雪场）
- 教练 / 雪友：需要把一次滑行拆解成可复盘的数据
- 佩戴 Apple Watch 的用户：希望手表端直接看到关键指标

**核心场景**

1. 上山前：查看雪场天气、5 日预报与雪质指数，决定去哪条道
2. 滑行中：一键开始记录，后台持续定位，实时看速度/坡度，自动识别雪场
3. 摔倒时：跌倒检测触发，提示是否联系紧急联系人
4. 下山后：回看轨迹、对比个人最佳、让 AI 教练点评、生成分享卡片

**成功指标**

- 一次完整滑行（记录 → 结束 → 生成卡片）不超过 3 次点击
- 记录过程中不出现因定位丢失导致的轨迹断裂
- 分享卡片在社交平台上一眼能看懂速度、最长距离与雪场

## 2. 产品原则

以下为全局业务规则，所有变更必须遵守：

- **离线可用**：雪场无网络时也能记录、统计、分享，核心能力不放在云端
- **不打扰**：后台定位只在记录中开启，结束即停；不索取无关权限；权限在功能首次使用时申请
- **手套可用**：关键按钮点击区域不小于 60 pt
- **隐私**：滑行数据默认只存本机；开启 iCloud 同步后写入用户自己的 CloudKit 私有库

## 3. 范围

**已有能力（MVP 与第二、三阶段，2026-03 前完成，见 [docs/history/](history/)）**：GPS 记录、地图、历史、
统计与成就、分享卡片、雪场识别、天气与雪质、AI 教练、跌倒检测、视频录制、Apple Watch 同步、CloudKit 同步、中英双语。
其中部分实现未接入界面，见 [architecture.md](architecture.md#并行--未接线的实现修改前先确认)。

**非目标**

- 不做账号体系与社交关系链
- 不把核心能力迁移到必须联网的云服务

### F1 滑行评分引擎

| 字段 | 内容 |
| --- | --- |
| 问题/目标 | 滑雪者希望滑行结束后立刻看到「这次滑得怎么样」的结论，而不是一堆数字 |
| 实施范围 | 纯逻辑评分引擎 `Services/RunScoreEngine.swift` + 单元测试 `SkiPalTests/RunScoreEngineTests.swift`。界面接入另立 [F1-UI](#f1-ui-滑行评分详情页接入) |
| 规则 | 输入一次 `SkiSession`；输出 0–100 总分 + 线路/节奏/体能三项分 + 三条可执行建议（顺序：线路、节奏、体能）。速度单位 m/s；负速度或 > 30 m/s 的点作为 GPS 噪声丢弃。详细评分规则维护在源文件头 |
| 验收标准 | ① 单元测试覆盖空轨迹、单点轨迹、异常速度、极短距离边界；② `xcodebuild` 在 iPhone 15 模拟器目标构建通过 |
| 原规格差异 | 原规格的输入还包括"雪质指数"，并要求规则写在 `requirements.md`；现有代码只以 `SkiSession` 为输入，规则写在源文件头。决定（2026-11-07）：**不把雪质指数纳入评分输入**——手机传感器无法测量雪质，仅能依赖存疑的外部数据或用户主观输入，会削弱「每一分均可由客观轨迹解释」的优点；将来做天气模块时可作为环境背景提示，相关想法降级至 [roadmap 后续评估](roadmap.md#候选想法)。规则写在源文件头、不单独维护 `requirements.md`：接受此差异 |
| 批准依据 | 原草拟规格列入范围；用户于 2026-11-06 同意"F1 记为实施中"，并授权对当前代码执行本机可用模拟器构建和 F1 测试。最终产品范围未单独确认；原 iPhone 15 验收要求保留，本机验证作为补充证据 |
| 工作状态 | 待验收：本机构建与现有测试通过；原 iPhone 15/CI 验收未执行，规格差异与覆盖缺口待处理 |
| 交付状态 | 已提交本地（当前保存提交，未推送、未发布） |
| 证据 | [2026-11-06 验证记录](evidence/F1-2026-11-06.md)：基于 `5704143` 的未提交工作区，Xcode 27.1 / iPhone 17（iOS 26.1）构建通过，10 个独立 F1 测试通过；负速度过滤分支未被现有用例覆盖。代码：[RunScoreEngine.swift](../ios/SkiPal/SkiPal/Services/RunScoreEngine.swift)、[RunScoreEngineTests.swift](../ios/SkiPal/SkiPalTests/RunScoreEngineTests.swift) |
