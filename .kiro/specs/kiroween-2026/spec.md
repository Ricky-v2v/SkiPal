# 规格：Kiroween 2026 参赛期增强

> 状态：草拟（类别与最终范围待确认）｜语言：中文

## 背景

SkiPal 已有完整 MVP：GPS 轨迹记录、地图、历史、统计与成就、分享卡片、天气与雪质、
AI 教练、跌倒检测、视频录制、Apple Watch 同步、CloudKit 同步。

Kiroween 2026 的评审重点之一是「AI 开发工具的实际用法」与「产品完成度」，
因此本次参赛期内的开发目标是把已有功能打磨成可演示、可讲述的产品，
并把规格、steering、hooks 等 Kiro 工作流沉淀进仓库。

## 用户故事

1. 作为滑雪者，我希望滑行结束后立刻看到「这次滑得怎么样」的结论，而不是一堆数字。
2. 作为滑雪者，我希望在雪场阳光下也能一眼看清数据（深色高对比、大字号）。
3. 作为评审，我希望能按 README 与规格文档自行把项目跑起来并复现核心体验。

## 范围

### F1 滑行评分引擎（AI 教练增强）

- 输入：一次会话的速度曲线、距离、海拔、坡度分布、雪质指数
- 输出：0–100 的本次评分 + 三条可执行建议（线路、节奏、体能）
- 规则以规格形式固化在 `requirements.md`，可被单元测试逐条验证

### F2 暗色高对比「雪地可读」主题

- 现有深色主题的基础上统一字号与对比度，关键数值使用等宽数字
- 所有新增界面沿用同一套颜色语义（accent / onAccent / 警告色）

### F3 演示与文档

- 根目录 README 补齐功能矩阵、构建步骤、截图与演示视频链接
- 提供 3 分钟以内的演示脚本，覆盖「记录 → 结束 → 评分 → 分享卡片」主链路

## 非目标

- 不做账号体系与社交关系链
- 不把核心能力迁移到必须联网的云服务

## 验收

- 单元测试覆盖评分引擎的边界（空轨迹、单点轨迹、异常速度）
- `xcodebuild` 在 iPhone 15 模拟器目标上构建通过
- README 中的构建步骤可在干净环境复现
